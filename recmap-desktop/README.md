# 🎙️ RecMap Desktop Recorder

تطبيق سطح مكتب خفيف ومستقل مبني باستخدام **Electron** و **TypeScript**، مصمم لتسجيل الاجتماعات والمحادثات مباشرة من شاشة وصوت النظام مع الميكروفون بضغطة زر واحدة، ثم رفعها وتحليلها تلقائياً على منصة [RecMap](https://recmap.tech).

---

## 🌟 الميزات الرئيسية

1. **التقاط مزدوج للصوت (Dual Audio Capture)**:
   - التقاط صوت النظام بالكامل (System Audio Loopback) بدون الحاجة لاختيار الشاشة يدوياً.
   - التقاط صوت الميكروفون مع إلغاء الصدى والضوضاء.
   - دمج القناتين في قناة واحدة متزامنة عبر Web Audio API.

2. **حماية قصوى من فقدان التسجيلات (Instant Local Backup)**:
   - حفظ فوري لنسخة احتياطية من الملف على القرص الصلب (`%APPDATA%\recmap-desktop\Recordings`) قبل الرفع، لضمان عدم ضياع أي ثانية حتى لو انقطع الإنترنت.

3. **واجهة عائمة خفيفة (Always on Top)**:
   - نافذة صغيرة مخصصة وقابلة للسحب ومثبتة دائماً بالأعلى.
   - مؤشر مرئي لمستوى الصوت (Live Audio Visualizer).
   - عداد زمني وزر إيقاف/تشغيل سريع.

4. **تكامل مباشر مع Supabase و Next.js API**:
   - نافذة تسجيل دخول متوافقة مع حسابك على الموقع.
   - طلب رابط رفع موقع (Signed Upload URL) عبر `/api/upload-url`.
   - إرسال طلب التحليل التلقائي إلى `/api/process-audio`.

## 🚀 التشغيل والاختبار المحلي

### 1. تشغيل التطبيق محلياً:
```bash
cd "D:\claude\Hesh rec\recmap-desktop"
npm run dev
```
أو بالنقر المزدوج على ملف `run_dev.bat`.

### 2. البناء كملف تنفيذي (Windows Installer / Portable .exe):
```bash
npm run dist
```
سينتج ملف التثبيت داخل مجلد `dist-installer/`.
